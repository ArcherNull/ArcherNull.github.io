需要在拍照tab中加入拍摄策略模块 / 识别策略模块，这两个都需要放在单帧拍摄模块上方

1、拍摄策略
是否自动拍摄switch，默认为否

开启自动拍摄时，需要展示出拍摄时间间隔（时间间隔最低3s，最高60s，默认值为5s）
当点击拍摄按钮时，就表示自动拍摄开始了，这个时候按钮的文本应该变为关闭自动拍摄，当点击关闭自动拍摄，就停止自动拍摄
画布上需要有倒计时拍摄的提示

关闭自动拍摄时，不需要展示拍摄时间间隔
当点击拍摄按钮时，就只能单张拍摄


2、识别策略
识别勾选复选框（只能勾选一个，或者不勾选），选项有：识别条形码、识别二维码、识别身份证、识别银行卡、识别国内发票、识别营业执照（在手电筒按钮旁边有识别条形码、识别二维码、识别身份证三个快捷的识别勾选框，是这里的快捷方式）

如果勾选了一个，那么则展示识别成功加入相册switch / 识别内容重复switch，如果不勾选，则不展示识别成功加入相册switch / 识别内容重复switch

识别成功加入相册switch，默认为否，当选择了是，并且识别勾选复选框勾选了一个识别类型，那么需要将内容识别出来，变成拍摄识别图片的文件名，才能加入到相册中

识别内容重复switch，默认为是，当选择了是，拍摄识别图片的文件名，需要命名 XXXX-1、XXXX-2；当选择了否，拍摄识别图片的文件名不能与相册中的文件名重复

【注意】识别条形码、识别二维码、识别身份证、识别银行卡、识别国内发票、识别营业执照的识别内容用于命名
识别条形码，识别的内容应为条形码编号
识别二维码，识别的内容应为二维码编号
识别身份证，如果是正面，识别的内容应为身份证号；如果是反面，识别的内容应为签发机关+有效期限
识别国内发票，识别的内容应为发票号码
识别营业执照，识别的内容应为统一社会信用代码
