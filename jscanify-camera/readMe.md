# 高拍仪工作台 · 功能说明

对应文件：`jscanify-camera.html`

---

## 一、功能汇总介绍

本页面是一套基于浏览器的**高拍仪 / 文档扫描工作台**，用纯前端技术替代传统 Dynamsoft Camera SDK，面向文档拍摄、矫正裁剪、条码识别、证件 OCR、人脸检测等场景。

### 技术底座

| 能力 | 技术 |
|------|------|
| 摄像头预览 | 浏览器 `getUserMedia` |
| 文档边缘检测 / 透视矫正 | OpenCV.js + jscanify |
| 条形码 / 二维码 | `@zxing/library` |
| 证件 / 发票等 OCR | 浏览器端 PP-OCRv6（按需加载） |
| 人脸检测 / 活体 | face-api.js + 本地 FLXC ONNX（按需加载） |

### 能力一览

1. **摄像头与预览**：打开 / 关闭 / 暂停摄像头，切换设备与分辨率，画面缩放与适配，旋转，移动端手电筒。
2. **文档扫描**：实时边缘高亮、透视纠偏、拍摄时自动裁剪文档；支持本地图片高亮检测与裁剪提取。
3. **拍摄与相册**：单张拍摄、自动连拍（带倒计时）、整帧拍照、连续取帧缓冲；底部相册支持预览、下载、重命名、清空。
4. **识别策略联动拍摄**：拍摄时可按策略识别条码 / 二维码 / 身份证 / 银行卡 / 发票 / 营业执照，并用识别内容命名入库。
5. **图片识别模块**（相机 Tab）：扫码识别、浏览器 OCR、人脸识别；支持上传图优先于摄像头画面。
6. **结果与预览**：扫码 / OCR / 人脸结果弹窗；拍摄图预览编辑（缩放、旋转、剪裁、文档再裁剪、保存）。
7. **运行日志**：记录关键操作与异常，可检测摄像头权限。

> 访问要求：需通过 **localhost** 或 **HTTPS** 打开，才能使用摄像头。

## 二、界面结构

页面分为四块：

| 区域 | 说明 |
|------|------|
| **顶部栏** | 产品名称、运行状态、分辨率、FPS、jscanify 版本 |
| **左侧舞台** | 摄像头预览、文档高亮叠加、人脸框、ROI 框选、自动拍摄倒计时 |
| **右侧面板** | 四个 Tab：相机 / 扫描 / 拍摄 / 日志 |
| **底部相册** | 拍摄记录缩略图与操作 |

舞台底部主操作：打开摄像头、关闭、暂停、拍摄、旋转、手电筒，以及快捷识别勾选（条形码 / 二维码 / 身份证 / 人脸）。

## 三、功能详细介绍与操作说明

### 1. 启动与摄像头控制

**功能说明**

- 页面加载后先初始化 OpenCV / jscanify 等 SDK，完成前界面有「SDK 加载中」遮罩，完成后可操作。
- 支持选择摄像头（含高拍仪）、预设分辨率，可刷新设备列表、探测当前实际分辨率。
- 支持画面适配（contain / cover）、CSS 缩放（0.5×～3×）、顺时针旋转 90°。
- 手电筒：仅在类移动端设备显示；可开关闪光灯。

**操作步骤**

1. 等待顶部状态从加载变为可用（或点击「SDK 初始化」重试）。
2. 在 **相机 → 设备** 中选择摄像头与分辨率（可选「刷新设备」「探测当前分辨率」）。
3. 点击舞台栏 **打开摄像头**。
4. 需要时使用 **暂停 / 关闭 / 旋转 / 手电筒**。
5. 在 **画面适配** 中调整 Video Fit、缩放，或点「重置缩放」。

---

### 2. 文档扫描（扫描 Tab）

**功能说明**

- **实时高亮边缘**：在预览上勾画文档四边形轮廓，可调检测间隔、颜色、线宽。
- **纠偏（透视矫正）**：开启后会联动边缘高亮；拍摄时对歪斜文档做透视矫正裁剪。建议文档放在对比明显的纯色背景上。
- **拍摄时自动裁剪**：`extractPaper`，可配置输出宽高（默认约 A4 @150dpi：1240×1754）；未检测到文档时回退为整帧。
- **本地图片扫描**：上传本地图后做「高亮检测」或「裁剪提取」，不依赖摄像头。

**操作步骤**

1. 打开摄像头后，切换到 **扫描** Tab。
2. 按需开启「实时高亮边缘」「纠偏」「拍摄时自动裁剪」，并设置输出尺寸与检测参数。
3. 摆正文档，确认高亮框贴合纸张后，点舞台栏 **拍摄**（会按纠偏 / 裁剪策略处理）。
4. 或选择本地图片 → **高亮检测** / **裁剪提取**。

---

### 3. 拍摄策略与单帧拍摄（拍摄 Tab）

#### 3.1 拍摄策略（自动拍摄）

**功能说明**

- 「是否自动拍摄」默认关闭；关闭时，「拍摄」为普通单张拍摄。
- 开启后显示 **拍摄时间间隔**（3～60 秒，默认 5 秒）。
- 开启后点击「拍摄」：开始自动连拍，按钮文案变为「关闭自动拍摄」，画布显示倒计时；再点一次停止。
- 关闭自动拍摄开关后，恢复单张拍摄。

**操作步骤**

1. 进入 **拍摄** Tab → **拍摄策略**。
2. 打开「是否自动拍摄」，设置间隔秒数。
3. 点舞台栏 **拍摄** 开始连拍；点 **关闭自动拍摄** 停止。

#### 3.2 识别策略

**功能说明**

识别类型为**单选或全不选**（互斥）：

- 识别条形码、识别二维码、识别身份证、识别银行卡、识别国内发票、识别营业执照

舞台栏「识别条形码 / 二维码 / 身份证」是上述策略的**快捷勾选**；「识别人脸」为独立实时预览，与识别策略互斥。

勾选任一识别类型后，额外显示：

| 开关 | 默认 | 含义 |
|------|------|------|
| 识别成功加入相册 | 否 | 开启后：仅识别成功才入库，并用识别内容作文件名；失败则不入相册 |
| 识别内容重复 | 是 | 开启：同内容命名为 `XXXX-1`、`XXXX-2`…；关闭：与相册已有文件名冲突则拒绝入库 |

**命名所用识别内容**

| 类型 | 文件名来源 |
|------|------------|
| 条形码 | 条形码编号 |
| 二维码 | 二维码编号 |
| 身份证正面 | 身份证号 |
| 身份证反面 | 签发机关 + 有效期限 |
| 国内发票 | 发票号码 |
| 营业执照 | 统一社会信用代码 |

未开启「识别成功加入相册」且识别失败时，可能以 `unknown` 序列命名仍入库；开启则失败不入库。

**操作步骤**

1. 在 **拍摄 → 识别策略**（或舞台快捷勾选）中选择一种识别类型。
2. 按需打开「识别成功加入相册」「识别内容重复」。
3. 打开摄像头并对准目标，点 **拍摄**（或开启自动拍摄后连拍）。
4. 等待识别完成，查看 toast / 日志，并在底部相册确认文件名。

#### 3.3 单帧拍摄与连续取帧

**功能说明**

- **抓取当前帧**：抓取当前画面帧（受纠偏 / 裁剪等策略影响，与「拍摄」逻辑相关）。
- **拍照（整帧）**：始终保存原始整帧，不做透视纠偏裁剪。
- **连续取帧缓冲**：按设定间隔（ms）连续取帧，可开始 / 停止，并显示缓冲状态。
- **打开最近拍摄预览**：进入预览编辑器。

**操作步骤**

1. 摄像头开启后，在 **单帧拍摄** 中点「抓取当前帧」或「拍照（整帧）」。
2. 需要批量取帧时，设置间隔 → **开始连续取帧** → 完成后 **停止**。
3. 点 **打开最近拍摄预览** 进入编辑。

---

### 4. 图片识别模块（相机 Tab）

通过三个子模式切换（可勾选显示对应面板）：

#### 4.1 扫码识别

**功能说明**

- 支持上传图片；有上传图时优先识别上传图，否则对摄像头画面轮询识别。
- 操作：扫码识别条形码、扫码识别二维码、框选识别（仅摄像头画面）、查看识别结果。
- 框选：在预览上拖动框选区域后识别。

**操作步骤**

1. **相机 → 图片识别模块** 勾选「扫码识别」。
2. 可选：拖拽 / 点击上传图片。
3. 点「扫码识别条形码」或「扫码识别二维码」；或点「框选识别」后在画面上拖选区域。
4. 点「识别结果」查看表格记录（可清空）。

#### 4.2 浏览器 OCR 识别

**功能说明**

- 开启后按需加载 PP-OCRv6（CDN、检测模型、识别模型，带进度）。
- 有上传图优先识别上传图，否则用当前摄像头画面。
- 能力：通用 OCR、身份证、银行卡、发票、营业执照；结果含原图 / 标注图 / 文本。

**操作步骤**

1. 勾选「浏览器 OCR 识别」，打开「开启 OCR」开关，等待模型加载完成。
2. 可选上传图片。
3. 点击对应识别按钮 → 「识别结果」查看。

#### 4.3 人脸识别

**功能说明**

- 开启后按需加载 face-api.js 与活体模型。
- **人脸检测**、**活体检测**：摄像头活体连拍 4 帧；上传图则复用单图。
- 舞台「识别人脸」：实时框选、置信度与活体预览（与识别策略互斥）。

**操作步骤**

1. 勾选「人脸识别」，打开「开启人脸识别」，等待模型就绪。
2. 可选上传图片后点「人脸检测」或「活体检测」。
3. 或在舞台勾选「识别人脸」做实时预览。
4. 点「识别结果」查看记录。

---

### 5. 拍摄相册与预览编辑

**功能说明**

- 底部展示拍摄记录数量与缩略图。
- 单张可：**预览、下载、重命名、删除**；整体可 **清空相册**。
- 预览编辑器支持：滚轮 / 按钮缩放、旋转 90°、框选剪裁、重置、文档透视再裁剪、保存修改回相册。

**操作步骤**

1. 拍摄成功后在底部相册查看缩略图。
2. 点击缩略图或「打开最近拍摄预览」进入编辑。
3. 使用放大 / 缩小 / 旋转 / 剪裁 / 文档裁剪等，确认后「保存修改」。
4. 需要本地文件时点「下载」；需要改名时用「重命名」。

---

### 6. 运行日志（日志 Tab）

**功能说明**

- 记录 SDK 初始化、开闭摄像头、拍摄、识别成败、命名结果等。
- 可清空日志、检测摄像头权限。

**操作步骤**

1. 切换到 **日志** Tab。
2. 查看 `logBox` 中的运行信息。
3. 需要时点「清空」或「检测摄像头权限」。

## 四、推荐使用流程（简版）

### 场景 A：文档高清扫描入库

1. 打开摄像头 → **扫描** 开启纠偏 / 自动裁剪 → 对准文档 → **拍摄** → 相册下载。

### 场景 B：拍摄并按证件 / 条码命名

1. **拍摄 → 识别策略** 勾选类型，按需开「识别成功加入相册」→ **拍摄** → 确认文件名后下载。

### 场景 C：仅识别不拍摄

1. **相机 → 图片识别模块** 选择扫码 / OCR / 人脸 → 上传或开摄像头 → 点对应识别按钮 → 看识别结果弹窗。

### 场景 D：批量自动拍摄

1. **拍摄策略** 开启自动拍摄并设间隔 → 点 **拍摄** 开始连拍 → 画布倒计时 → 点 **关闭自动拍摄** 结束。

---

## 五、注意事项

1. 必须使用 **localhost** 或 **HTTPS**，否则摄像头不可用。
2. OCR、人脸模型体积较大，首次开启需等待 CDN / 模型下载。
3. 文档扫描效果依赖背景对比度；纯色背景、文档平整时纠偏更稳。
4. 识别策略与舞台「识别人脸」互斥，勿同时依赖两者。
5. 「识别成功加入相册」开启时，识别失败不会写入相册。
6. 「识别内容重复」关闭时，同名内容会拒绝入库，需先处理相册中的同名文件。
